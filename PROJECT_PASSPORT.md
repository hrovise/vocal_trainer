## 🛠️ 2. Технологический стек (Tech Stack)

### Ядро и фреймворк
* **Фреймворк:** Flutter 3.38.3 (Channel stable)
* **Язык программирования:** Dart 3.10.1
* **Графический конвейер:** Аппаратный рендеринг GPU (Skia / Impeller). 60 FPS бегущий неоновый спектрограф звука на кастомном `CustomPainter` без дропов кадров.

### Аудио-подсистема
* **Захват звука с микрофона:** `record: 5.1.2`
  * Низкоуровневый прямой захват аудиопотока через нативные плагины Android (`record_android`) и Windows WASAPI (`record_windows`).
  * Запись сжатого голоса без потерь в `.m4a` (AAC LC, 44.1 кГц, 128 kbps).
* **Воспроизведение и плеер:** `audioplayers: ^6.7.1`
  * Встроенный плеер для мгновенного прослушивания своего записанного голоса («▶️ Слушать себя»).
  * Бесшовный бесконечный луп (`ReleaseMode.loop`) для опорных нот камертона.
* **Синтезатор эталонных тонов (Rhodes Piano Engine):**
  * Кастомный in-memory генератор PCM 16-bit WAV-буферов (`lib/services/tone_generator.dart`).
  * Синтезирует теплый звук электропиано Rhodes: фундаментальная частота $f_0$ (72% веса) + 2-я гармоника (20%) + 3-я гармоника (8%).
  * Фазовое выравнивание под целочисленное число периодов для устранения кликов и щелчков при зацикливании.
  * 3 переключаемые октавы камертона: Бас ($C2: 65–131\text{ Гц}$), Речь ($C3: 131–262\text{ Гц}$), Высокий ($C4: 262–524\text{ Гц}$).

### Модули тренировки речи
* **Дикторский таймер:** 2-минутный интерактивный секундомер для методики винной пробки / карандаша.
* **Тренажёр артикуляции:** Программа разминки челюсти, освобождения гортани и стрельбы взрывными согласными слогами (`ПТКУ-ПТКО...`).

## 🗄️ 3. База данных: Hive NoSQL

В проекте используется **Hive** (`hive: ^2.2.3`, `hive_flutter: ^1.1.0`) — ультрабыстрая, легковесная key-value встраиваемая база данных на чистом Dart.

### Почему именно Hive, а не SQLite?
1. **0 байт внешних зависимостей C/C++:** Не требует нативных библиотек `sqlite3.dll`, исключая ошибки несовместимости ABI на Windows и Android.
2. **Экстремальная скорость:** Hive работает напрямую с оперативной памятью и сохраняет бинарные боксы (`.hive`) на диск, работая в 5–10 раз быстрее традиционных реляционных БД.
3. **Безопасность и автономность:** Все данные хранятся локально в системной директории приложения (`path_provider`).

### Модель данных (`VoiceRecord` — бокс `voice_records`)

| Поле | Тип | Описание |
|---|---|---|
| `id` | `String` | Уникальный таймштамп записи (мс) |
| `title` | `String` | Название замера («🎯 Исходный замер (ДО)» / «Замер №...») |
| `createdAt` | `DateTime` | Дата и точное время проведения замера |
| `filePath` | `String` | Абсолютный локальный путь к сохранённому `.m4a` файлу на устройстве |
| `durationSeconds` | `double` | Длительность аудиозаписи в секундах |
| `pitchStabilityScore`| `double` | Процент устойчивости голосового тона (0–100%) |
| `avgFrequencyHz` | `double` | Средняя базовая частота связок в герцах ($f_0$) |
| `isBaselineBefore` | `bool` | Флаг эталонного замера «ДО» для расчета чистого прогресса |
| `notes` | `String` | Сводка: определенный тип голоса, граничные ноты, октавы и полутона |

## 🧠 4. Искусственный интеллект & Модель анализа: 100% On-Device AI

> [!IMPORTANT]
> **Приватность голоса и нулевой бюджет ($0 Cloud Cost):**  
> В приложении **не используются** сторонние облачные нейросети (OpenAI, Gemini API, Whisper Cloud). Пользовательские голосовые слепки являются чувствительными биометрическими данными. Вся аналитика выполняется на $100\%$ локально на чипе устройства (CPU / DSP) без интернета.

### Алгоритм классификации голоса (`lib/services/voice_classifier.dart`)
1. **Спектральный анализ:** Поток аудио сэмплируется с частотой 44.1 кГц, алгоритм автокорреляции YIN и Zero-Crossing Rate отсекает шумы дыхания и выделяет устойчивые пики основного тона ($f_0$).
2. **Логарифмический расчет диапазона:**
   $$\text{Octaves} = \log_2\left(\frac{f_{\max}}{f_{\min}}\right), \quad \text{Semitones} = \text{round}(\text{Octaves} \times 12)$$
3. **Матрица классификации по системе Fach (10 мировых тембров):**
   * **Мужские:**
     1. 🌋 **Бас-Профундо (Октавист):** $A1 – C3$ ($55–130\text{ Гц}$). Опорные ноты: $C2, E2, G2, C3$.
     2. 🧔 **Центральный Бас:** $E2 – A3$ ($82–220\text{ Гц}$). Опорные ноты: $E2, G2, B2, D3$.
     3. ⚡ **Бас-Баритон:** $G2 – D4$ ($98–294\text{ Гц}$). Опорные ноты: $G2, C3, E3, G3$.
     4. 🎙️ **Драматический Баритон:** $A2 – E4$ ($110–330\text{ Гц}$). Опорные ноты: $A2, C3, E3, A3$.
     5. 📻 **Лирический Баритон:** $B2 – F\#4$ ($123–370\text{ Гц}$). Опорные ноты: $B2, D3, F3, B3$.
     6. 🎺 **Драматический Тенор:** $C3 – A4$ ($131–440\text{ Гц}$). Опорные ноты: $C3, E3, G3, C4$.
     7. 🕊️ **Лирический Тенор:** $D3 – C5$ ($147–523\text{ Гц}$). Опорные ноты: $D3, F3, A3, D4$.
   * **Женские:**
     8. 🌹 **Контральто:** $D3 – F4$ ($147–349\text{ Гц}$). Опорные ноты: $D3, F3, A3, D4$.
     9. 🌸 **Меццо-Сопрано:** $F3 – C5$ ($175–523\text{ Гц}$). Опорные ноты: $F3, A3, C4, F4$.
     10. 💎 **Сопрано:** $B3 – E5$ ($247–659\text{ Гц}$). Опорные ноты: $A3, C4, E4, A4$.

## 🔒 5. Права доступа (Permissions) и Безопасность

### Android Permissions (`android/app/src/main/AndroidManifest.xml`)
* `android.permission.RECORD_AUDIO` — **Обязательное.** Захват звука с микрофона для тюнера и диктофона.
* `android.permission.WRITE_EXTERNAL_STORAGE` / `READ_EXTERNAL_STORAGE` (`maxSdkVersion="32"`) — сохранение аудиозамеров в изолированную директорию приложения. На Android 13+ доступ осуществляется через безопасный `MediaStore`.
* `android.permission.MODIFY_AUDIO_SETTINGS` — переключение аудиопотоков при воспроизведении эталонного звука.

> [!NOTE]
> **Zero Spyware:** Приложение **НЕ** запрашивает доступ к интернету (`INTERNET` permission в релизе Android можно отключить вовсе), геолокации, камере, контактам, фотогалерее или Bluetooth.

### Windows Desktop Permissions
* Использует стандартные права пользователя Windows. Захват микрофона осуществляется через Windows Core Audio (WASAPI). Не требует прав Администратора.
